# Code of Conduct

## Our standard

mnesio is a technical project and we want it to be a good place to do technical
work. Everyone participating — in issues, pull requests, discussions, and any
other project space — is expected to be respectful and constructive.

In practice:

- **Critique the work, not the person.** "This bypasses hard rule #1 because…"
  is useful. "This is garbage" is not.
- **Assume competence and good faith.** Contributors have different backgrounds
  and different amounts of context. Ask before assuming a mistake was careless.
- **Be direct and be kind.** Blunt technical disagreement is welcome; contempt,
  personal attacks, and dismissiveness are not.
- **Accept that the maintainers may say no.** A rejected PR is a decision about
  scope, not a judgement about you.

Harassment of any kind is not tolerated. That includes personal or political
attacks, insults, demeaning comments, publishing others' private information
without permission, unwelcome sexual attention, and sustained disruption of
discussions.

## Adopted standard

This project adopts the [Contributor Covenant v2.1][cc] as its full code of
conduct. Where this page is brief, the Covenant governs — please read it.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Scope

This applies in all project spaces, and also when someone is representing the
project in public — for example posting from an official account or speaking as
a maintainer at an event.

## Reporting

If you experience or witness unacceptable behaviour, report it to the
maintainers privately via GitHub's private vulnerability reporting on this
repository (**Security → Report a vulnerability**), which is the most reliable
private channel available on a repository of this size. Reports will be handled
discreetly, and we will not retaliate against anyone who reports in good faith.

Maintainers will review and respond as promptly as they can. Consequences for
violating this code of conduct range from a private warning, through a temporary
block from project spaces, to a permanent ban — proportionate to the behaviour
and to whether it is repeated.

Maintainers who do not follow or enforce this code of conduct in good faith may
face the same consequences.
